PDFRepo stands for PDF Repository, a tool designed to manage and organize PDF files efficiently. 
It provides features such as searching, categorizing, and annotating PDFs, making it easier for 
users to handle large collections of documents.

The main features of PDFRepo include:

    **Importing PDFs**: Users can upload and import PDF files into the repository for centralized 
	   management and control.
	**Exporting PDFs**: Users can export selected PDFs or entire collections for sharing or backup purposes.
	**Search Functionality**: Users can quickly find specific PDFs using keywords, tags, or metadata.
	**Categorization**: PDFs can be organized into folders or categories for better management and 
		PDF document selection.
	**Annotations**: Users can add notes, highlights, and comments as metadata to PDFs for better 
		understanding and collaboration.
	**Backup and Restore**: The tool provides options to back up the entire repository and restore it when 
	    needed, ensuring data safety. It is stronly suggested that the backup is done regularly to avoid 
		data loss and most importantly, that the backup is stored in a secure location such as OneDrive 
		or other cloud storage.
	***User-Friendly Interface**: PDFRepo as a Windows Forms applicationoffers an intuitive and easy-to-use
	    interface, making data easilyaccessible 
		to users of all technical levels.
	**Encryption and Security**: The tool ensures that PDF files are stored securely, with options for 
		encryption and access control to protect sensitive information.
